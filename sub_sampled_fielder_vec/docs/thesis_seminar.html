Part I

Phylogenies, Trees
& STDR

The object

A phylogenetic tree

A rooted binary tree \(T=(V,E)\). The \(m\) terminal nodes (leaves) \(X=\{x_1,\dots,x_m\}\) are species we observe today.

The \(m-1\) internal nodes \(H=\{h_1,\dots,h_{m-1}\}\) are unobserved ancestors — we never see them directly.

Everything we know comes from data at the terminals.

From terminals to data

From aligned sequences to a latent tree

each terminal node carries a row of the alignment \(X\in\{A,C,G,T\}^{m\times\ell}\); the tree itself is latent
The target

The split

Cutting a single edge of the tree partitions the leaves into two groups:

\[ X \;=\; A \,\cup\, B \]

Each side is a clan — the leaf set of one root subtree (the unrooted analogue of a clade).

root split → clan A (blue) vs clan B (orange)

Part II

The Sub-Sampling
Problem

The problem

We only observe a sparse random subset of \(S\), reweighted to be unbiased:

\[ \hat S_{ij}=\tfrac{1}{p}\,\Omega_{ij}S_{ij},\qquad \mathbb{E}[\hat S]=S \]

What is the minimal \(p\) for correct recovery w.h.p., and in what scale?

observed entries colored · unobserved dark · p ≈ 0.5
A reframing

It's an eigenvector perturbation problem

Because \(\mathbb E[\hat S]=S\):

\[ \hat L = L + E_L,\qquad E_L=\hat L - L \]

So the question: how much does \(E_L\) move the Fiedler vector?

\[ \|E_L\|_2 = \|(\hat{D}-D)-(\hat{S}-S)\|_2 \;\le\; \|E_D\|_2 + \|E_S\|_2 \]
Part III

Building \(S\)

From DNA sequences to similarity matrix

Three Biological Assumptions

MOLECULAR CLOCK
rate = const → depth = time
All lineages evolve at the same rate — branch lengths equal elapsed time
GTR MODEL
\(S_{ij}=e^{-\alpha(d_1+d_2+d_3)}\)
Similarity decays exponentially along the connecting path
Building \(S\) step by step

What Each Assumption Means for \(S\)

MOLECULAR CLOCK
uniform rate
→
\(S_{ij}\) depends only on the MRCA depth \(d(i,j)\) — not on which taxa specifically
GTR MODEL
reversible Markov
→
\(S_{ij} = e^{-\alpha\, d(i,j)}\) for some \(\alpha > 0\) — similarity decays exponentially with separation
The algebraic structure

The Constant Block Model (CBM)

Under the three assumptions, cross-clan similarities collapse to a single constant \(\beta_0\):

\[ S_{ij}=\beta_0 \ \ (i\in A,\,j\in B),\qquad S_{ij}>\beta_0\ \ (i,j\text{ same clan}) \]
\[ S=\begin{pmatrix} S_A & \beta_0 J\\ \beta_0 J & S_B \end{pmatrix} \]
\[ L=\begin{pmatrix} D_A-S_A & -\beta_0 J\\ -\beta_0 J & D_B-S_B \end{pmatrix} \]

The cross block \(\beta_0 J\) is rank-1 — that structure makes the spectrum tractable.

Part IV

Bridging Tree Topology
to Linear Algebra

Tree geometry → spectral quantities

Tree Geometry: Imbalance & Structural Margin

IMBALANCE
\(\eta := |B|/|A| \geq 1\)
ratio of the larger clan to the smaller
STRUCTURAL MARGIN
\(\rho = S_{\text{in}}^{\min} - S_{\text{out}}^{\max}\)
gap between weakest in-clan and strongest cross-clan similarity
Tree geometry → spectral quantities

The Spectral Bridge

COHERENCE  ↔  IMBALANCE
\(\mu(U) = \dfrac{1+\eta}{2}\)
SPECTRAL GAP  ↔  SPECTRAL MARGIN
\(\Delta\lambda \geq m_{\min}\,\rho - \eta \cdot m_{\min} \cdot S_{\text{out}}^{\max}\)
Part V

Theoretical Guarantee

From sub-sampling error to eigenspace error

Perturbation Theory

Let \(M\) and \(\tilde M = M + H\) be symmetric. How do eigenvalues and eigenvectors change?
THEOREM 1 · WEYL
\(|\lambda_i - \tilde\lambda_i| \leq \|H\|\)
Eigenvalue perturbation bounded by the operator norm of H
THEOREM 2 · DAVIS–KAHAN
\(\sin\theta \leq \dfrac{\|H\|_2}{\delta}\)
\(\theta\) = angle between \(\tilde v_2\) and \(v_2\);  \(\delta = \min(\lambda_2 - \lambda_1,\;\lambda_3 - \lambda_2)\)
The perturbation error in the Fiedler vector

Setting Up the Bound

SETUP
Write \(\hat L = L + E_L\) and set \(w := \hat v^{(2)} - v^{(2)}\)
STANDARD \(\ell_2\) ROUTE — Davis–Kahan
\(\|w\|_2 \leq \dfrac{\|E_L\|_2}{\Delta\lambda - \|E_L\|_2}\)
Project the perturbed eigenvalue equation onto the orthogonal complement of \(v^{(2)}\) and apply Weyl.
Why \(\ell_2\) bounds are not enough

Recovery is an Entry-Wise Event

The top-down partition succeeds precisely when the empirical Fiedler vector agrees in sign at every node.
RECOVERY CRITERION
\(\|\hat v^{(2)} - v^{(2)}\|_\infty < \min_i\,|v^{(2)}_i|\)
An \(\ell_2\) bound is too coarse — it controls average error across nodes, but recovery fails if even one node has the wrong sign. We need an \(\ell_\infty\) bound.
From \(\ell_2\) to \(\ell_\infty\) — the key lemma

Neumann Decomposition

LEMMA
Define \(w^{(1)}\) and \(w^{(2)}\) by
\(w^{(1)} := \displaystyle\sum_{\ell \neq 2} \dfrac{-\langle v^{(\ell)},\, E_L v^{(2)}\rangle}{\lambda_\ell - \hat\lambda_2}\,v^{(\ell)}, \qquad w^{(2)} := \displaystyle\sum_{\ell \neq 2} \dfrac{-\langle v^{(\ell)},\, E_L w\rangle}{\lambda_\ell - \hat\lambda_2}\,v^{(\ell)} + \langle v^{(2)}, w\rangle\,v^{(2)}\)
Then \(w = w^{(1)} + w^{(2)}\) exactly.
w(2) IS NEGLIGIBLE
\(\|w^{(2)}\|_\infty = O\!\left(\|E_L\|_2^2 / \Delta\lambda^2\right)\) — second order in the perturbation. Only \(w^{(1)}\) matters; its structure allows applying matrix Bernstein concentration in \(\ell_\infty\).
Proof sketch — how the pieces connect

Main Result

MATRIX BERNSTEIN
\(\|E_L\|_2\) bounded w.h.p. when \(p\) is large enough
SPECTRAL GAP — TREE GEOMETRY
\(\Delta\lambda \geq m_{\min}(\rho - \eta\,S_{\mathrm{out}}^{\max})\)
⇩
NEUMANN DECOMPOSITION
\(\|w\|_\infty \;\leq\; \|w^{(1)}\|_\infty \;+\; \underbrace{\|w^{(2)}\|_\infty}_{\displaystyle O(\|E_L\|_2^2/\Delta\lambda^2)} \;\leq\; \dfrac{\|E_L\|_2}{\Delta\lambda} + O\!\left(\dfrac{\|E_L\|_2^2}{\Delta\lambda^2}\right)\)
⇩
RECOVERY CRITERION
\(\|w\|_\infty < \min_i|v^{(2)}_i|\)  —  correct sign at every node
⇩
\(p \;>\; \dfrac{8(1+\eta)^3\,\beta_0^2\,\ln(2m/\delta_0)}{m\,\bigl(\rho - \eta\,S_{\mathrm{out}}^{\max}\bigr)^2} \quad\Longrightarrow\quad p \;=\; O\!\left(\dfrac{\log m}{m}\right)\)
\(\eta\)  — imbalance: \(S_{\mathrm{out}}^{\max} / S_{\mathrm{in}}^{\min}\) (tree geometry)
\(\beta_0\)  — \(\max_i|v^{(2)}_i|\) (Fiedler vector scale)
\(\rho\)  — \(S_{\mathrm{in}}^{\min}\): minimum within-clan similarity
\(\delta_0\)  — failure probability; bound holds w.p. \(\geq 1-\delta_0\)
